# 需求与验收

选题 2：内容任务规划 Agent。用户是需要在预算和截止时间内制作内容活动方案的运营人员。

输入主题、预算、截止时间，可选内容形式偏好。交付包含活动目标/受众假设、素材引用、脚本、任务计划、实际步骤依赖与状态、工具结果、费用和耗时、已保存方案或明确未完成原因。素材与工具费用均为合成数据，业务预算单位为模拟单位。

本期采用单用户 CLI 和本地状态库，提供检索、估算、生成、保存工具。真实模型选择动作并接收工具观察；执行器负责预算、时间、状态和次数限制。离线 Mock 经过同一执行器，只用于流程验证。界面、部署、多 Agent、远端业务副作用和跨运行续跑不在范围内。

| 必验收点 | 可观察成功标准 |
|---|---|
| 正常完成 | standard 费用 8.00；先检索、估算、生成、重估、保存，再合法结束 |
| 缺预算/截止时间 | 一次列明缺失项，零模型/工具调用，awaiting_input |
| 预算超限 | 看到 12.00 后改选 8.00；仅有 12.00 时返回缺口 2.00 |
| 工具失败 | 原失败保持 failed，检索结果保留；替代或明确停止 |
| 重复执行 | 同 ID 同条件零新增；条件变更拒绝；新 ID 独立执行 |
| 部分结果 | 保留内容和缺口，状态 failed/partial，不收费，不用作成功依赖 |
| 时间与上限 | 不忽略模型等待，不重置历史耗时，最后一轮没有额外调用 |
| 真实动态决策 | DeepSeek 两条真实路径已取得：12→8；生成失败后改选 lean，详见评估 |

完整、权威需求见 [spec.md](../specs/001-content-planning-agent/spec.md)，治理规则见 [constitution.md](../.specify/memory/constitution.md)。实现与测试映射见 [评估](03-evaluation.md)，避免维护相互冲突的第二份详细规格。


审查后细化：各档位仅交付一份结构化脚本草稿（短视频分镜/图文正文/单段精简文案），报价不包含实际拍摄、设计或投放。引用事实逐字溯源，模型创意与运营规则建议显式待审核；保存完成不等于已获发布确认。实际步骤依赖必须按所用产物的来源连接，详见 [修复验收](07-review-fixes.md)。
